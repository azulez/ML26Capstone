Earnings Call Excess Return Signal

Paste raw earnings-call transcript text below. The model splits it into speaker turns, scores each with FinBERT, and predicts whether the stock's excess return (vs. S&P 500) over the lag window is likely positive or negative.

Transcript text needs specific formatting to parse into speaker turns -- see format examples if you get a "No speaker turns found" error.


Known limitation: on held-out test data, this model achieves ~49-50% accuracy -- effectively no better than a coin flip. It is deployed as a demonstration of the end-to-end pipeline, not as a source of real trading signal. See docs/deployment.md for details.
